# بامبات — صفحة هبوط مالية (React + TypeScript + Vite + Tailwind)

صفحة هبوط عربية **RTL بالكامل** لشركة مالية متخصصة في **PAMM**، **الاكتتابات** و**الباقات الاستثمارية**.
الواجهة فقط (Front-end only) — بدون باك اند، بدون تسجيل حساب، بدون لوحة تحكم.
كل أزرار التواصل تفتح **واتساب** أو **تيليجرام** مباشرة.

## التقنيات

| العنصر | المستخدم |
| --- | --- |
| اللغة | TypeScript |
| الإطار | React 18 |
| الأداة | Vite 5 |
| التصميم | Tailwind CSS 3 (ثيم مخصص: أبيض + أخضر) |
| الاتجاه | `dir="rtl"` + خط عربي (Cairo / IBM Plex Sans Arabic) |

## التشغيل محليًا

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # بناء الإنتاج في مجلد dist
npm run preview  # معاينة نسخة الإنتاج
```

## النشر على Vercel

المشروع جاهز للنشر مباشرة (يوجد ملف `vercel.json`):

1. ارفع المشروع إلى GitHub ثم **Import Project** في Vercel.
2. الإعدادات (تُكتشف تلقائيًا):
   - **Framework**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. اضغط **Deploy**.

أو عبر CLI:

```bash
npm i -g vercel
vercel --prod
```

## تخصيص المحتوى

كل البيانات مركزة في ملفين:

- `src/config/site.ts` — اسم الشركة، روابط واتساب/تيليجرام، روابط النافبار والفوتر، نصوص التحذير.
- `src/data/content.ts` — نصوص الواجهة الرئيسية (`HERO_COPY`)، ركائز التفوق (`ADVANTAGES`)، جميع الباقات
  (السعودية، الإمارات، الكويت، الدولار)، فئة رجال الأعمال، الاكتتابات، أنظمة الاشتراك، طرق الدفع، خطوات الرحلة، الأسئلة الشائعة.

### تغيير روابط التواصل

```ts
// src/config/site.ts
export const CONTACT = {
  whatsapp: 'https://wa.me/9665XXXXXXXX', // الرقم بصيغة دولية بدون +
  telegram: 'https://t.me/your-channel',
}
```

### تغيير الألوان

الثيم في `tailwind.config.js` — الهوية **أبيض + أخضر**:

```js
ink:   // الأسطح الفاتحة (أبيض / أخضر فاتح جدًا) + درجات النص الداكن — ink-50 … ink-950
brand: // الأخضر الأساسي للهوية (أزرار، تدرجات، لمسات) — brand-50 … brand-950
```

- الشريط الجانبي (قائمة الهاتف) يستخدم الكلاس `.side-panel` في `src/index.css` — خلفية خضراء صلبة **غير شفافة** ونص أبيض.
- لوحة CTA الأخيرة خضراء صلبة بنص أبيض، وبقية الأقسام بيضاء بلمسات خضراء.

## المميزات المنفّذة

- ✅ صفحة RTL كاملة بخط عربي فاخر وثيم **أبيض + أخضر**
- ✅ قسم «كيف نضمن تفوقك في السوق؟» بركائز ثلاث (اكتتابات منتقاة / إشارات بامب مدروسة / نظام حماية متكامل) + اختصارها داخل بطاقة الواجهة الرئيسية
- ✅ نافبار ثابت مع scrollSpy، شريط جانبي أخضر (غير شفاف) للهاتف، وقائمة تواصل (واتساب/تيليجرام)
- ✅ 40+ بطاقة باقة موزّعة على 4 أسواق + فئات رجال الأعمال، وتُعرض **مقسّمة على دفعات** بدل عرضها كاملة دفعة واحدة
- ✅ تبويبات ثابتة (sticky) تنقل لقسم كل دولة
- ✅ نافذة تفاصيل لكل باقة مع زرّي واتساب وتيليجرام
- ✅ قوائم تواصل عبر Portal (لا تُقص داخل البطاقات)
- ✅ حركات ظهور تدريجية عند التمرير + احترام `prefers-reduced-motion`
- ✅ أكورديون الأسئلة الشائعة، أقسام قانونية، شريط تقدّم القراءة
- ✅ تصميم متجاوب بالكامل (هاتف، تابلت، سطح المكتب)
- ✅ تحذيرات المخاطر وإخلاء المسؤولية في الأماكن المطلوبة

> ⚠️ تنبيه: محتوى الأقسام القانونية نص template عام — يُستحسن مراجعته مع المستشار القانوني للشركة قبل النشر.
